Cara menayangkan di GitHub Pages
1. Buat repo publik bernama farrelandika.github.io
2. Upload index.html dan folder images/ ke repo (Add file > Upload files)
3. Settings > Pages > Source: branch main, folder /root > Save
4. Buka https://farrelandika.github.io (tunggu 1-2 menit)

Yang perlu diisi: cari "ISI SENDIRI" di index.html (link LinkedIn, CV, sertifikat),
lalu MANGA, VIDEOS, dan CAFES di bagian script. Taruh foto di folder images/
dan tulis path-nya, misalnya src:"images/punpun.jpg".
